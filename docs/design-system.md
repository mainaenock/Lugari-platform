# Design system

## Colour and typography

The light theme uses an off-white page, forest green navigation and actions, and warm amber for emphasis. The dark theme has its own contrast-adjusted surfaces and foregrounds. CSS variables in `src/app/globals.css` define reusable tokens for both themes. Status chips use explicit text labels so meaning survives changes to colour and contrast. Manrope is self-hosted. Body copy begins at 16 px and headings use a fluid scale.

## Layout and interaction

The header includes grouped navigation, search, locale, theme and Data Saver. Mobile uses a collapsible menu and a persistent shortcut bar. Page content uses consistent cards, headings, forms, focus rings, empty states and source labels. Search uses a native dialog and a keyboard shortcut. Form inputs have persistent labels and error messages. Bars include textual values and table headers indicate their scope.

Data Saver reduces imagery and motion and hides the project location view. The operating system’s reduced-motion preference takes precedence. Print styles remove navigation and interactive controls. The first English/Kiswahili translations cover the header, main search, home hero and shortcuts. Dated directory content retains its source language.

## Photography

Use a named development record for each archival image. Project detail pages include descriptive alt text, captions and a source link. The homepage uses a road-works photograph from the archive and identifies the location. WebP variants are sized for mobile cards and larger screens. The visual language relies on local places and infrastructure.
